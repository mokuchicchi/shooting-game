# ZANGE

HTML / CSS / JavaScript だけで作った縦スクロールのシューティングゲーム。
小・中・大の鳥ボスを倒すと、最後に3形態のザビエルが現れる。

## 遊び方
`index.html` をブラウザで開く（ダブルクリックで動きます）。

## ファイル構成と担当の分け方の例
| ファイル | 中身 |
| --- | --- |
| `js/game.js` | 全体の進行（タイトル・ボス戦・クリア）、画面のUI、起動処理 |
| `js/bosses.js` | ボス4体の設定。動き・HP・攻撃パターン（`BOSS_DEFS`） |
| `js/bullets.js` | 敵の弾とレーザーの見た目・動き・当たり判定 |
| `js/player.js` | 自機の移動・ショット・ボム・被弾 |
| `js/background.js` | 背景。画像を読み込み、雲の流れ・火の粉・光・霧・稲妻だけをコードで動かす |
| `js/input.js` / `js/sound.js` | キー・タッチ入力、効果音（Web Audio） |
| `css/style.css` | ページのレイアウト |
| `img/` | ボスの画像 |
| `img/bg/` | 背景画像（夜空・雲・聖堂。すべて480×720。雲は上下がつながっていてループできる） |

## 動作確認用の隠しコマンド
`↑ ↑ ↓ ↓ ← → ← →` と入力すると（タイトルでも戦闘中でもOK）無敵モードになる（もう一度入力で解除）。
無敵モード中は戦闘中に `K` キーで今のフェーズを飛ばせる。

## いじりやすい場所
- ボスの強さ：`js/bosses.js` の各フェーズの `hp` と、`every('名前', 間隔)` の間隔（小さいほど弾が増える）
- 自機の残機・ボム数：`js/player.js` の `this.lives` / `this.bombs`
- 新しいボス：`BOSS_DEFS` に1つ追加し、画像を `game.js` の `loadImages` に足す
